# Component-Sourcing Preflight — shared Input primitive (settings focus, #150)

Record for the settings-input portion of issue #150. The four `/settings`
text fields shared one native `<input>` className that ended in
`focus:outline-none` with no replacement indicator; the 2026-08-24 a11y
baseline records them as the 8 remaining observed missing focus indicators
(4 inputs x 2 viewports). This record covers the one shared primitive that
replaces that className. It was first written on 2026-08-30 in an unpushed
clone and re-applied on 2026-09-14 after a hunk-by-hunk comparison against
`origin/dev`.

- Target app/surface and component job: mission-control-kanban `/settings` —
  one accessible, reusable text Input with a visible `focus-visible` ring and
  invalid/disabled/file-input states, on the app's existing `mc-*` tokens.
- Target-app component checked: the app had no `src/components/ui/input.tsx`;
  the four affected settings fields repeated the same native input classes.
  Existing `ui/card.tsx`, `ui/tabs.tsx`, and `lib/utils.ts` establish the local
  copy-owned shadcn style and the `cn` convention this file follows.
- Component Marketplace primitive checked: the private Component Marketplace
  was considered but not copied; no redistributable Input primitive was
  established there, and the public pinned shadcn source supplies the exact
  missing primitive.
- External pools checked or deliberately skipped: inspected shadcn-ui/ui Input
  at commit `b4a618b97e35f5dadf3a00d51f410c84a2567d4d`, file
  `apps/v4/registry/new-york-v4/ui/input.tsx` (blob
  `f1124aea14eee062fc2f4c55dad5f0d9de0ccc1a`, re-checked via the GitHub API on
  2026-09-14). Magic UI, KokonutUI, React Bits, Motion.dev, and Bklit were
  deliberately skipped because this is a form primitive already covered by
  the app's shadcn conventions, not a motion or decorative block.
- Chosen source lane and why: pinned public shadcn source, manually adapted.
  The structural baseline (typed native input props, `data-slot`, `cn`,
  visible-focus, invalid, disabled, and file-input states) is retained.
  Tailwind 4 theme shorthands and unified-Radix assumptions are replaced with
  this Tailwind 3 app's existing `mc-*` tokens. No registry installer or new
  framework is used.
- License/access/dependency result: shadcn-ui/ui is MIT at the pinned commit
  ([LICENSE.md](https://github.com/shadcn-ui/ui/blob/b4a618b97e35f5dadf3a00d51f410c84a2567d4d/LICENSE.md));
  the inspected
  [Input source](https://github.com/shadcn-ui/ui/blob/b4a618b97e35f5dadf3a00d51f410c84a2567d4d/apps/v4/registry/new-york-v4/ui/input.tsx)
  is copy-owned for internal app use and adds no dependency.
- Proof expected before closeout: `npm run test:a11y-remediation` and
  `node scripts/verify-component-sourcing-preflight.mjs` pass; ESLint and
  `tsc --noEmit` pass; then a caller-faithful
  `node scripts/probe-surface-a11y.mjs` sweep on a production serve reports
  zero `/settings` input focus misses at both published viewports, and the
  captured surfaces are re-recorded on that serve (any `src/` edit moves
  `sourceDigest`).
- Covers: src/components/ui/input.tsx
